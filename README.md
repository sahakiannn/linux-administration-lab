# Linux Administration Lab 🚀

## Overview

This repository contains my hands-on Linux Administration practice and documentation.

The goal of this project is to build practical experience with Linux system administration, command-line operations, user management, permissions, networking, services, and basic automation using Bash scripting.

This lab is part of my DevOps learning journey and focuses on real-world system administration skills.

---

## Objectives

- Understand Linux system architecture
- Practice Linux command-line administration
- Manage users, groups, and permissions
- Configure and troubleshoot basic networking
- Work with Linux services and processes
- Create automation scripts using Bash
- Document technical knowledge using Git and GitHub
